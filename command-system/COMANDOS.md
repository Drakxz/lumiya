Os nomes curtos são apresentados na Central de Comandos. Os antigos continuam
funcionando como aliases, com os mesmos argumentos e permissões. Use `!ajuda`
para consultar todos os comandos disponíveis para você.

Os comandos já curtos ou claros foram mantidos:
`!ban`, `!backup`, `!backups`, `!restaurar`, `!unbanall`, `!chat`, `!hall`,
`!painel`, `!tempo`, `!ficha`, `!top`, `!gestao`, `!upadmin` e `cl`.

Os comandos de barra (`/`) permanecem com os nomes atuais. Os nomes internos,
as configurações salvas, os IDs dos botões e os controles de permissão não mudam.
`shortcuts.js` centraliza a tradução dos prefixos e dos exemplos na inscrição
dos comandos. Ao adicionar um atalho, os testes de inicialização verificam
que ele existe no bot real e que o prefixo anterior continua funcionando.
